# 🎬 Movie Booking Platform

An interactive and responsive web application for browsing movies and booking tickets. This project is built using Vanilla JavaScript and dynamically manages data through a local JSON structure.

## 📝 Project Description
This platform provides a seamless user experience for cinema enthusiasts. It features a modern interface where users can discover trending movies, filter through different genres, and view detailed information before proceeding to ticket booking. The project demonstrates advanced DOM manipulation, event handling, and asynchronous data fetching.

## ✅ Features Checklist
- [x] **Dynamic Movie Slider:** Interactive slider with auto-updating background images on hover/selection.
- [x] **Real-time Filtering:** Search functionality to find movies by title and a dropdown to filter by genre.
- [x] **Movie Details Modal:** Detailed pop-up window showing the plot, rating, release year, and poster for each movie.
- [x] **Booking Integration:** Direct link to a seat selection page (`seats.html`) with movie title parameters.
- [x] **Theme Toggle:** Fully functional Dark and Light mode support.
- [x] **Responsive Grid System:** A flexible layout that adapts to mobile, tablet, and desktop screens.
- [x] **JSON Data Integration:** Centralized data management using a `movie.json` file for easy updates.

## 🛠️ Built With
- **HTML5:** Semantic structure for better accessibility.
- **CSS3:** Custom styling with Flexbox, Grid, and Backdrop filters.
- **JavaScript (ES6+):** Dynamic rendering, Fetch API, and URL parameter handling.
